# GitHub Profile Finder

A clean, responsive web app that lets you search any GitHub username and instantly view their profile data — avatar, bio, repos, followers, following, location, blog and join date.

## Built With
- HTML5
- CSS3 (3D effects, animations, responsive design)
- Vanilla JavaScript (Fetch API, async/await)
- GitHub Public API (no API key required)

## Features
- Search any GitHub user by username
- Displays avatar, name, bio, stats and info
- Error handling for users that don't exist
- Loading animation while fetching
- Fully responsive on mobile

## What I Learned
- Fetch API and how to make GET requests
- async/await syntax and error handling
- Working with a real public REST API
- DOM manipulation to display dynamic data
- JSON parsing and reading API responses
